# User Experience MOC

Authority level: User Experience.

This level owns the default value journey, interaction contract, visible state, control boundaries, proof of value, failure recovery, variations, measures, and experience principles.

Status: confirmed as the implementation baseline. The canonical contract defines automatic extension-initiated pairing with a readable profile-local code and no copied broker code; the extension-backed CDP command-and-event journey; managed-tab targeting; one separately installed and uniquely named endpoint per participating profile; distinct-endpoint workspace capacity in selected or focus-defaulted existing windows; automatic workspace replacement and opener-child adoption; ticket-first asynchronous execution; full-cycle acceptance-ordered same-tab execution; owner-scoped ticket access; explicit controls; and orderly recovery. Operational defaults close the prior debugger-detach, event retention, endpoint continuity, status freshness, broker-restart continuity, endpoint-control authority, payload, polling, and compatibility gates while keeping numeric limits and runtime adaptations evidence-tunable.

## Canonical User Experience contract

- [`User-Experience-Definition.md`](./User-Experience-Definition.md) owns the agent journey, installation journey, asynchronous execution and direct-read interaction contract, workspace and tab acquisition journey, extension-backed CDP default and supporting use cases, visible results, control boundaries, success evidence, experience principles, and Product traceability.
- [`Operational-Defaults.md`](./Operational-Defaults.md) owns the testable recovery, continuity, status, request-access, payload, polling, and compatibility defaults needed by the downstream contract.
